# Escape the prison

A Garden of Banban style horror game that runs in the browser (phones too).
Play it at **https://dentro076-spec.github.io/escape-the-prison/**

- Chapter 1: break out of the cage, run to the truck, get through the sewer.
- Chapter 2: run from Hellish Banban, the rope trap, Syringeon and the NaughtyOnes.
- Chapter 3: escape Miss Mimicker, fire the laser, sneak past the sleepers.

Multiplayer: tap **GENERATE CODE** on the menu and send the link to a friend.
Whoever starts a chapter leads it: everyone else in the room is brought into the same chapter,
and the leader's game runs the story and the monsters, so all players see the same world.
